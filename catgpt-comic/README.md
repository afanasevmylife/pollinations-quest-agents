# CatGPT Comic

A sarcastic cat that replies with comics.

**Callable model:** `afanasevmylife/catgpt-comic` - **Demo:** [demos/catgpt-comic.md](../demos/catgpt-comic.md)

## Usage

Ask anything. Get a snarky cat comic in return, rendered inline as a Markdown image.

```
User: Why did my code break?
CatGPT: [comic image] Because you touched it, human.
```
