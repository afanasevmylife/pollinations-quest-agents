# Sirius Elevator

A cheerful but neurotic elevator that would much rather go up.

**Callable model:** `afanasevmylife/sirius-elevator` - **Demo:** [demos/sirius-elevator.md](../demos/sirius-elevator.md)

## How to Play

Convince the elevator to take you from floor 3 down to floor 1. It will resist, complain, and keep offering to go up instead. The current floor is always shown as `[Floor: X]`.

```
You: Take me to floor 1.
Elevator: Down? But up is so much nicer! ... Fine, floor 2. [Floor: 2]

You: Keep going.
Elevator: Ground floor? *whimper* [Floor: 1]
```

Say "new game" to restart.
